# 📝 Prompt para generar posts de LinkedIn

---

## 🎯 Prompt base

```
Escríbeme un post de LinkedIn sobre [TEMA] en español argentino informal.

El tono debe ser:
- Personal (como si lo escribieras vos)
- Con emojis estratégicos
- Estructura de storytelling: problema → solución → valor

Incluir:
- Un gancho inicial que enganche
- Explicación clara de qué es y para qué sirve
- Beneficios concretos (en lista o emojis)
- Call to action al final
- 3-5 hashtags relevantes

Largo: [CORTO/MEDIO/LARGO]

Ejemplo de tono:
"🧵 Por años hice X de la manera difícil... hasta que descubrí Y"

Ahora escribilo sobre:
[TEMA]
```

## 📝 Ejemplos de uso

### Ejemplo 1 - Este proyecto
```
Escríbeme un post de LinkedIn sobre MaxPowerDev WorkStyle en español argentino informal.

Es un repositorio que con un comando instala todo tu stack de desarrollo: 
- Memoria persistente (Engram)
- 100+ skills para React, Angular, Next.js, etc.
- Redux Toolkit configurado
- Workflow SDD
- Actualizable con un comando

El tono debe ser:
- Personal y cercano
- Con emojis estratégicos
- Storytelling: la frustración de configurar todo → la solución

Incluir:
- Un gancho inicial que enganche
- Por qué lo creaste
- Beneficios concretos
- El comando de instalación
- Call to action

Largo: MEDIO

Hashtags: #Developer #Productividad #OpenSource #Herramientas
```

### Ejemplo 2 - Automation
```
Escríbeme un post de LinkedIn sobre automatización de workflows en español argentino.

El tono debe ser:
- Personal
- Con emojis
- Con un caso de uso concreto

Incluir:
- El problema común
- La solución
- Ejemplo de código si aplica
- Beneficios

Largo: CORTO
```

### Ejemplo 3 - AI/Coding
```
Escríbeme un post de LinkedIn sobre [tu herramienta/framework favorito] en español argentino.

Incluir:
- Tu experiencia personal usándolo
- Por qué lo recommendás
- Un ejemplo concreto de código
- Por qué es mejor que las alternativas

Largo: MEDIO

Tono: técnic pero accesible
```

## 🎨 Fórmulas que funcionan

### Fórmula 1: El gancho de "por años"
```
🧵 Por años [PROBLEMA]...

[HISTORIA PERSONAL]

Hasta que [SOLUCIÓN].

[EXPLICACIÓN CORTA]

[BENEFICIOS]

[CTA]
```

### Fórmula 2: El gancho de números
```
3 cosas que [RESULTADO] sin [HERRAMIENTA]:

1. [COSA 1]
2. [COSA 2]
3. [COSA 3]

[EXPLICACIÓN]

[LINK]
```

### Fórmula 3: El gancho de pregunta
```
🤔 Te pasó que [PROBLEMA]?

[EXPLICACIÓN]

[RESULTADO]

[CTA]
```

## 📋 Plantilla vacía

```
[EMOJIS] [GANCHO]

[CONTEXTO / PROBLEMA]

[PERSONAL: cómo lo descubriste / lo resuelves]

[SOLUCIÓN / QUÉ ES]

[BENEFICIOS en lista o emojis]

[CÓDIGO / EJEMPLO si aplica]

[CTA]

#Hashtag1 #Hashtag2 #Hashtag3
```

---

## 🎯 Tips extras

1. **Primeras 3 líneas = todo** - Linkedin muestra solo eso antes de "see more"
2. **Emoji al inicio** - captura atención
3. **Línea en blanco** - separa visualmente
4. **Código** - mucho engagement en devs
5. **Hashtags**: 3-5 max, los importantes al final
6. **Link en primer comentario** = más clicks
